# Original de Pacman.py
Este es un juego de pacman que fue modificado para que el tablero tenga una distribución diferente y que los fantasmas vayan más rápido. 
Es importante recordar que pacman se juega con las teclas arrow que permiten moverlo en 4 direcciones (arriba, abajo, izquierda, derecha). 
Pacman es el personaje principial y se muestra de color amarillo. Tiene el objetivo de comer todos los puntos rojos mientras huye de los fantasmas.

Los cambios que se realizaron hacen que el juego sea más díficil, estos cambios fueron: 

La matriz fue modificada para tener más callejones sin salida. 
El color del tablero paso de azul a gris.
Los fantasmas cambiaron de color rojo a azul. 
Los puntos a recoger cambiaron de blanco a verde y luego a rojo. 
Los fantasmas se hicieron más rápidos.

Como sugerencia, en el futuro se puede modificar más para que el juego se reinicie al ganar o que la matriz se haga de forma aleatoria.
